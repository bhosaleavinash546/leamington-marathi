# Should-cost report review — Supplier Quality / Quality Engineer

Reviewer role: automotive supplier quality engineer (IATF 16949, PPAP, safety-critical parts).
Material read: all 21 pages of `rpt0/UK/stub-axle-cast-machine.pdf` and its workbook, the 14 other UK PDFs and workbooks (rule
tables, operations, Not-included text, DFM findings), and `rpt0/CN/stub-axle-cast-machine.pdf` for currency and text in my area.
Where I went to the code to confirm a finding, I name the file. I changed no files.

**Summary.** The tool costs the quality *yield* (reject rates) consistently and visibly in the rule tables, and the safety-critical NDT
station is a reasonable, labelled default. Gear is the model to copy: it names the items it left out ("No straightening allowed for",
"No shot peening allowed for"), puts load QC in the heat-treat rate and charges an inspection master as tooling. The main gaps:
1. Every report's "Not included" lists only freight and duty. PPAP, gauges, traceability marking, cleanliness, corrosion protection,
   leak tests the route does not charge, and heat treatment are missing from the list, so a reader assumes they are in the price.
2. Scrap on the machining stage of cast + machine and forge + machine parts is 0%. Machining from solid carries 2% for the same
   operations.
3. A report-builder bug prints an unticked checkbox as "on (edited)". The vent pipe report therefore claims a pressure test that is
   not costed.
4. Some standards statements are loose: EN 1563, the ISO 8062-3 RMA wording, and a NADCA die-casting citation used on a sand
   casting.

## B. Commodity matrix — quality view

"Core" = the quality lines a decision-maker needs on page one: what the price **includes** for quality, the reject rate and its £, and
the **Not included until answered** list. "Audit" = station build-ups, rule bases, face lists. The last column says which checks
apply and which must **not** apply.
