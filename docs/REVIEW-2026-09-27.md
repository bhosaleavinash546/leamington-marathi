stubbed (`scripts/fake-llm.mjs`) so nothing here cost a token. Method:

every route was rendered in both themes at two widths with axe, console,
network, type-floor, focus and reduced-motion probes; then the code behind
the findings was read and the fixes below were made and re-measured.

## 4. UI upgrades (the "world-class" layer, Wave 3 of the September review)

- **Live run panel** — phase rail Connect → Search → Reason → Write → Verify,
  elapsed clock, the server's token estimate labelled as an estimate, an
  event log with `@starting-style` entrances, `@property`-registered rail
  fill, and a Cancel that stops the bill. Nothing on it guesses ahead of the
  stream.
- **Results** — summary tiles count up with the shared `TickNumber`; the
  engine-verified share is a swept `ScoreRing` (the DFM dial, so one gauge
  reads the same everywhere); cards are keyboard stops (`j`/`k` or arrows
  move, Enter expands, `x` selects) with a visible ring and an on-page hint.
- **Command palette** — ↑/↓/Home/End/Enter/Esc, recents on an empty query,
  hover tracks the active row, key legend in the footer.
- **Theme change as a View Transition** — a circle growing from the toggle,
  guarded for no-API, reduced-motion and re-entry. DECISIONS 79.
- **Platform CSS** — `text-wrap: pretty` on every `.measure` paragraph,
  `text-wrap: balance` on page titles, `content-visibility: auto` on
  marketplace cards.
- **Storage that cannot throw** — one helper, tested, behind sign-in,
  onboarding, theme, palette recents, integrations, server URL, API-key
  fields, dashboard project cache.

Two things the run caught in the review's own tooling, kept here because
they are the kind of thing that makes a green result worthless: the stub's
first abort detector listened on the request, which Node closes as soon as
the body is read, so every reply was "aborted" and the cancel test hung for
five minutes on a stalled stream; and the first `@property` declaration did
not inherit, so the rail never moved. Both were found by looking at the
screenshots and the stub's counters, not by the tests passing.
