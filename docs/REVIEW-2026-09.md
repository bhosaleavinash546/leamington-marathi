# BrainSpark 360° review — September 2026

A measured review of the whole platform, one month after `AUDIT-2026-08.md`.
Method: every accuracy gate re-run, `npm run eval:status`, the corpus and
catalogue counted by script, and three line-anchored code surveys (frontend,
backend and security, engines and data). Every S1 below was re-verified by
hand at the cited line or by running the engine. The full narrative, the
improvement programme and the innovation register are in the published
review page; this file is the register the next review measures against.

**Basis legend.** MEASURED = ran it. CODE = read and verified at the line.
OPINION = judgement.

### Gates after implementation

| Gate | Before | After |
|---|---|---|
| Should-cost, held-out (14 parts) | hit 78.6% · MAPE 20.9% | **hit 92.9% · MAPE 15.2%** · band coverage 85.7% |
| Should-cost, calibrated (16 parts) | hit 100% · MAPE 8.3% | hit 93.8% · MAPE 11.0% (gate ≥90% / ≤12%) |
| Divergence held-out ÷ calibrated | 2.51× | **1.37×** (gate 2.8×) |
| Feature machining | relative-only gate | MAPE 34.3%, ceiling 35% |
| Feature stamping | relative-only gate | MAPE 39.5%, ceiling 40% |
| PCB v2 | relative-only gate | MAPE 29.4%, ceiling 30% |
| Ideation layer | not in CI | six gated numbers on a frozen corpus |
| Unit / integration / e2e | 1,084 / 22 / 8 | 1,166 / 22 / 8, axe 0 serious/critical |

The calibrated set moved the "wrong" way on purpose: it was 100% because the
engine had been fitted to it. The number that matters is the held-out set, and
the divergence between the two — 2.51× to 1.37× — is the measurement that says
the engine learned physics rather than fixtures.

## Programme (OPINION, ordered by value per day)

1. **Stop the bleeding**: R-1 to R-4, R-9 to R-14, R-5 to R-8. Days.
2. **One honesty layer, no silent failures**: a shared provenance badge component required wherever a saving renders (R-19 to R-22); a `failures` block in every pipeline summary (R-23); declared defaults (R-24); legacy seeds re-labelled unverified (R-18).
3. **Engine accuracy**: resolver as a covering map with a CI reachability test (R-26); region on the machine and the lane plus nine regions (R-27, R-28, R-37); feature engines to parity with calibration, yield, residual-derived band and an absolute gate (R-29, R-30, R-34, R-39); calibration on process × region × volume with LOO shown (R-32); material-aware cycle time from ~20 machined-part quotes (R-31); commodity bridge and FX (R-33); geometry-responsive scrap (R-38).
4. **Measure what is claimed**: R-39 to R-43.

## Prism, next accuracy step (OPINION)

Resolver first (every engine check passes through it); calibrated dossier with leave-one-out error on the cover; stamping feature engine behind the process lens for the lamination class; stage-failure reporting then a fresh live batch for the dedupe and repair rules; the research brief when egress allows; an engineer rating loop.
