# Go-live rehearsal — 4 September 2026

An end-to-end rehearsal of the deployed product, run the way an audience would
use it rather than the way a test suite does. The staged image contents were
booted in production mode on a clean database, every API route was hit with and
without credentials, every page was opened in a real browser against the
production build, and the demo path was walked by hand — signup, the engines, a
real STEP file through OpenCascade, Prism, exports.

Method note: there is no Docker daemon in the review environment, so the image
was **staged** — the Dockerfile's exact COPY set mirrored into a directory,
dev dependencies pruned, booted with `NODE_ENV=production`. That is what found
the two seed-file defects below; a `docker build` on your machine is still the
first real test of the image itself.

**Basis legend.** MEASURED = ran it. CODE = read and verified at the line.

## 2. What was found, and fixed

| ID | Sev | Found | Fixed | Proof |
|---|---|---|---|---|
| G-1 | S1 | **The marketplace was empty on the staged image.** `marketplace-legacy-seed-ideas.json` is read with `fs`, not imported, so the image-completeness test could not see it. The seed logged one ENOENT and carried on; health was green. | Added to the Dockerfile. | Count 0 → 657 |
| G-2 | S1 | **Then it held 657 ideas instead of 2,243.** The other nine seed packs are passed *by name* to `seedMarketplaceIdeasFromFile()`, invisible to a scan for `readFileSync('…')`. | `COPY marketplace-*.json`. The test now scans every `.json` string literal in reachable code that resolves to a real file, and requires ≥10 seed packs so it cannot pass vacuously. Verified by reverting the glob and watching it name the nine. | Count 657 → **2,243**, 10 seed passes, no errors |
| G-3 | S1 | **The homepage showed "Live commodity prices" with a green dot** over figures that were a 63-day-old baseline and had never once been updated from the web. Live updates need `BRAVE_API_KEY`; without it the refresh is 0/46 forever. Anyone in the audience who follows steel would notice. | `/api/prices` now carries `live`, `stale`, `asOf`, `basis`. The strip labels itself from those: **"Reference commodity prices · As of 3 Jul 26"** with a grey dot unless a web refresh has actually succeeded within a day. | Rendered in Chromium: label, dot class and date all correct |
| G-4 | S2 | **Forgot-password on a no-SMTP production server said "an OTP has been sent"** while the code went to the server log. A presenter who forgets their password on stage is stranded at the reset screen. | Returns 503 with an honest, enumeration-safe message: "not configured on this server — ask your administrator." | Live: HTTP 503 with the message |
| G-5 | S2 | **`CREDENTIALS_SECRET` was enforced ~900 lines after boot** — a misconfigured server opened the DB, seeded 2,243 ideas, then died. | Moved beside the `JWT_SECRET` check, before any work. | Boot without it: exit 1, **0** seed lines |
| G-6 | S2 | **The admin-bootstrap trap.** `ADMIN_EMAILS` blocks those addresses from signup; only `ADMIN_EMAIL`+`ADMIN_PASSWORD` seeds one. Set the first without the second on a fresh database and no administrator can ever exist — no error anywhere. | Preflight fails on an empty database with the block and no seed. | Preflight: `✗ admin bootstrap` on that configuration |
| G-7 | S3 | The Help page FAQ told users to run `npm run dev` and open `localhost:5173`. | Reworded for the person using it, not building it. | Bundle grep: 0 hits |

Stated, not fixed, because they are choices: Google Fonts is an external
dependency (system-ui fallback, layout holds — self-host if it matters on
stage); `BRAVE_API_KEY` unset means reference prices, now labelled as such.
Both are preflight NOTEs.

**One thing not explained.** During the first, concurrent harness run a
session was revoked mid-sweep. Two controlled reproductions — every page
visited in sequence, and the full unauthenticated route sweep against a live
token — did not reproduce it. Recorded here rather than dropped: watch the
logs for unexpected `signout` after go-live.

## 3. On the day

1. `docker compose exec brainspark node scripts/preflight.mjs` — **17 checks,
   read the NOTEs**. Green is necessary, not sufficient.
2. Sign in **before** you walk on. The session lasts a week; there is no
   reason to authenticate in front of people.
3. Add the Anthropic key in Settings before, not during. Every LLM feature
   returns a clear "no API key" without it — clear is not the same as
   impressive.
4. Have one real STEP file ready and open DFM Studio with it once, in the
   green room. It exercises the whole geometry layer; if it comes back, the
   riskiest path works.
5. Do not demonstrate password reset unless SMTP is configured. The app now
   says so honestly, which is better than lying, and worse than a working
   reset.
6. The commodity strip will say **Reference** unless you set `BRAVE_API_KEY`
   and a refresh has run. Either set it the day before, or say "reference
   prices" yourself before someone else does.
7. Generation takes 2–6 minutes and shows a log, not results, until it
   finishes (Prism review P-7, still open). Start it, talk over it, do not
   stare at it.
